# Team Practice

Complete this folder during Topic 3 before beginning assessed prototype development.

Your group will:

1. Create one member profile per person inside `members`.
2. Commit and push each profile from the correct GitHub account.
3. Pull the other members' contributions.
4. Complete the controlled conflict activity using `conflict-practice.txt`.
5. Complete `working-agreement.md` as a group.
6. Check that every local copy contains the final shared files.

Use the full practical instructions provided on Canvas.
