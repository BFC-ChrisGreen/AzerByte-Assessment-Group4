# Azerbyte Guides

These guides take your group through the main stages of the Azerbyte build.

Complete them in order and stop at each checkpoint. If the expected result does not appear, fix that stage before moving on.

| Guide | Focus |
|---|---|
| `01-working-as-a-group.md` | Clone the shared repository and practise the group Git workflow. |
| `02-your-first-api.md` | Build the first Flask endpoint and connect a separate Python client. |

Later guides will cover character data, SQLite, the Tkinter client and testing.
